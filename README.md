# Macco_app

A Flutter-based Njangi digital platform.

## 🚀 About

Macco_app (theyoungshallgrow) is a digital Njangi system built with Flutter and deployed via Railway.

Features include:

- 👥 Member management
- 📊 Dashboard panels
- 💰 Contributions tracking
- 🤖 AI panels
- 🌐 Web deployment support

## 🛠 Tech Stack

- Flutter
- Dart
- GitHub
- Railway
